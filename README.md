# DeadReckoning
**DEADNAVS** is an Android-based dead-reckoning and telemetry logging application designed for high-frequency motion tracking and navigational analysis. Engineered to capture synchronized kinematic datasets, the platform logs real-time readings from the device’s accelerometer, gyroscope, magnetometer, gravity sensor, and fused GPS location directly into structured CSV files for dead-reckoning research and algorithm validation. Integrated with the Google Maps SDK, DEADNAVS provides a high-performance vector map interface featuring live heading alignment, custom orientation tracking, and an ergonomic floating overlay UI that maintains continuous sensor sampling without interface latency.
